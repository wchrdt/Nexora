Набор zapret для обхода блокировок Discord и YouTube (Flowseal/zapret-discord-youtube).
Всё, что лежит здесь, вшивается в установщик. Класть файлы необязательно:
если папка пустая, Nexora сама скачает свежий набор с GitHub при первом включении обхода.

Чтобы работало сразу без интернета: распакуй сюда релиз с
https://github.com/Flowseal/zapret-discord-youtube/releases
так, чтобы получилось zapret\bin\winws.exe, zapret\lists\..., zapret\general.bat и т.д.

SoundCloud, sndcdn.com и soundcloud.cloud Nexora дописывает в lists\list-general-user.txt и lists\list-general.txt сама при каждом включении обхода.
Если GitHub недоступен или аккаунт автора набора снова приостановят, автообновление не сработает, но Nexora продолжит работать на вшитой копии: поэтому положи набор в эту папку перед сборкой.
