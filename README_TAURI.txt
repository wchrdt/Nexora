ОБНОВЛЕНИЕ ПО КНОПКЕ (1.9.22)
Настройки -> «Обновление приложения» -> «Проверить обновления»: приложение смотрит последний релиз на GitHub, скачивает установщик, ставит и перезапускается.
Первоначальная настройка (один раз):
 1. cargo tauri signer generate -w nexora-updater.key  (создаст пару ключей; приватный файл не публиковать).
 2. Публичный ключ вставить в src-tauri/tauri.conf.json -> plugins.updater.pubkey, а в endpoints подставить свой логин и репозиторий.
 3. В GitHub: Settings -> Secrets and variables -> Actions: TAURI_SIGNING_PRIVATE_KEY (содержимое приватного файла) и TAURI_SIGNING_PRIVATE_KEY_PASSWORD.
 4. Выпуск версии: поднять version в Cargo.toml и tauri.conf.json, затем git tag v1.9.23 && git push origin v1.9.23. GitHub Actions соберёт установщик и latest.json.
Старые версии без кнопки обновятся только вручную, новым установщиком.
